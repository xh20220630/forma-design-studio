# Forma · Rin Pearl Studio / 全站视觉重构 v4

## 设计依据与边界

新设计围绕已有 **凛 Rin** 展开：银白短发、冰蓝瞳、黑白非对称外套、蓝色方形发饰、冷淡表情与 Q 版比例。Logo 继续使用项目原始 `Brand.tsx` SVG；正式页面使用原始 IP 透明化素材，生成设计图中对角色线条的细小变化不作为重新设计 IP 的授权。

所有 12 张页面图由 **内置 image_gen** 逐页独立生成。设计图用于视觉方向，真实文字、表单、图标、画布和设计项目预览均由 HTML/CSS/SVG/已有渲染器实现。禁止将整张页面图当作可交互页面背景。

参考当前官方产品案例：
- [Linear 2026: A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh)：降低导航权重，统一位置栏与视图栏、通过柔和边界保持层级。
- [Figma: Making the move to UI3](https://www.figma.com/blog/making-the-move-to-ui3-a-guide-to-figmas-next-chapter/)：为作品让出空间、工具与内容形成明确层次。

本项目在这些原则上发展独有 IP 视觉：珍珠白工作台、墨黑侧栏、冰蓝玻璃创作场景和可辨识的原版凛。

## 图像与切图原则

1. 原IP从原素材提取 alpha；银发白衣内部不得误删、不得变更角色面部比例。
2. 主hero环境、角色、玻璃光效分层；文字/按钮在代码中排版。
3. 可切图：原创角色、复杂玻璃棚景、照片、复杂艺术封面、动效视频 poster。
4. 不切图：输入框、表格、导航、文字、普通几何控件、可编辑设计稿、通用图标。
5. 导出透明角色 PNG/WebP，场景 WebP，视频 WebM 加静态 poster。严格指定裁切范围及 alt。
6. 模板与项目已有真实设计内容时使用真实项目预览；示例图库封面可使用独立艺术素材，但不能假装是用户当前文件内容。

## 验收重点

- 每个 view 路由都有自己的设计图与对应功能结构。
- 无用户 IP 替换、Logo替换或品牌色丢失。
- 页面预览、组件、Token、同步文件等保持真实数据来源。
- 所有图案不挡住点击目标、内容焦点与输入框。
- 1366宽仍可用；窄屏应折叠侧栏/减少图库列数；画布面板独立滚动。
- 空/加载/成功/错误保留原Rin状态，不以纯装饰替代状态信息。

## 正式实现适配校正与生成图审核

截至交付，12 张图片均为 1536×1024 独立内置生图成品，全部保存在 designs/。已目视检查所有输出；12 张统一共享珍珠白 / 墨黑 / 冰蓝视觉系统，每页功能结构单独设计。

正式实现以真实源码与可访问性优先，对图示作以下明确修正：

- 根背景采用 #F6F8FC，深色侧栏采用 #191F29；原品牌 #38BDF8 保留。
- 主要按钮色采用 #0875E1，提高白色文字对比度；自定义强调色保留并派生适当操作颜色。
- 字体使用项目现有本地 Geist 包与中文系统回退，不增加外网字体请求。
- 主题工作室保留实际存在的 3 个主题；图10中6张主题卡属于视觉示例，不凭空增加无后端或状态支持的主题。
- 图中所有项目/页面数、组件数、状态、API模型名称、更新时间、仓库、分支和版本一律读取应用真实数据，不能硬编码图里的示例值。
- 图07自动补充的“不会用于模型训练”“不存储设计文件”等承诺没有代码依据，禁止复制。使用真实说明：项目与设置保存在本机；请求将设计上下文发往配置的模型服务。
- 图08自动补充的“自动创建提交”不是现有功能，禁止复制。同步沿用现有写入 forma-generated/ 的行为与冲突检查，不擅自提交或推送仓库。
- 图11左侧背景项目页面仅用于衬托聊天布局；正式项目总览仍按图02与真实业务实现，不引入图11生成的额外页面分组/分享按钮。
