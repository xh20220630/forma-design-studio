## 实现选择

主体是珍珠白工作台、墨色导航与冰蓝品牌场景。正式配色以 `apps/web/src/theme/StudioTheme.tsx` 和 `apps/web/src/studio-tokens.css` 为准：背景 `#f6f8fc`、导航 `#191f29`、正文 `#172134`、品牌浅蓝 `#38bdf8`。主要按钮采用更深的 `#0875e1` 配白字，替代设计图中的高亮蓝以改善可读性。字体沿用项目 Geist 和中文系统字体。

原 Logo、原版凛的银白短发、蓝瞳、黑白外套和蓝色发饰保持不变。透明化沿用原图像素与轮廓，不把生成设计图里的角色变化带入正式页面。原始素材保留，新文件放在 `apps/web/public/brand/rin/v4/`。

角色、摄影与环境质感使用独立切图；文字、图标、按钮、表单、图表和画布继续使用 React/CSS/SVG 与真实数据。项目卡片展示现有项目的实际画布。没有把整张设计图铺成页面。

首页接入 4 秒透明 WebM，附打包纹理的 Blender 源场景。它使用原角色的静态透明贴图，运动发生在周围画框与角标，不是角色骨骼动画。默认显示静帧，用户播放时才加载视频；支持停止、离屏暂停、后台暂停和减少动态效果。卡片提供轻微视差；任务指示与真实 busy 状态绑定。

## 验收记录

- `npm run build` 通过：包含 `tsc --noEmit` 和 Vite 生产构建。最后一次构建在最终响应式修复后完成。
- 未运行 lint；未运行 pnpm。
- 桌面浏览器逐页检查首页、项目概览、编辑器、模板、组件、变量、助手、同步、设置、主题、聊天与绑定弹窗。
- 验证项目网格/列表切换、搜索筛选、组件分类过滤、图层选择和属性联动、打开/关闭原型预览。主题切换与深色显示检查后恢复素白。
- 390px 与 768px 检查首页、模板、组件、变量、设置和主题；修复组件分类栏断点冲突与移动端插画裁切。检查移动端聊天、帮助和创建弹窗的关闭/滚动操作。
- 动效子任务验证透明通道、循环首尾、原图纹理一致、真实视频播放/停止及静帧退化，详见动效目录中的验证记录。
- 验收没有发送模型请求、创建/删除设计项目、绑定真实代码目录或执行代码同步。因此外部模型及同步写入流程不在本次交互实测范围内。

现有项目数据及其画布样式保留。工作台外观重构不会给用户已有的设计稿批量换肤。
