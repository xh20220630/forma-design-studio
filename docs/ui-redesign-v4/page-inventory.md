## 素材与实现边界

- 角色、复杂场景、材质和视觉装饰使用规范位图资产，按用途输出真实透明或完整背景。
- 文字、图标、按钮、表单、数据表、页面结构和交互热点使用真实 UI，保持清晰度、键盘访问和响应式。
- 图片生成图是视觉设计依据，不直接作为整个网页背景代替交互。
- 原项目预览继续渲染真实设计节点；概念图中的虚构数据不会写入用户项目。
- 动效响应减少动态效果偏好；循环视频在不可见或页面后台时停止，不占用设计画布的拖动事件。

## 验证

页面图与实现逐页核对；桌面与窄窗口检查溢出；核对关键操作、图片 alpha、视频播放与静帧回退。共享前端完成后运行一次生产构建（含 TypeScript），仅在新的问题或修改出现后重跑。
