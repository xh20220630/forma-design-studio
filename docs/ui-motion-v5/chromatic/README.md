# Chromatic Loom / 色彩织机

独立的 CSS 3D + Motion 材质交互动效，不使用图片序列、Canvas、WebGL或新增依赖；不改动凛的形象。

## 接入

```tsx
import { ChromaticLoom } from "./motion/ChromaticLoom";

<ChromaticLoom
  preset={settings.preset}
  accent={settings.accent}
  reducedMotion={motionOff}
/>
```

- `preset`: `paper | glacier | midnight`，直接使用工作台主题值。
- `accent`: HEX 品牌/自定义强调色。接受 `#RGB` 和 `#RRGGBB`，无效值回退原品牌 `#38BDF8`。
- `className?`: 外层布局扩展。
- `reducedMotion?`: 工作台动态效果开关；与系统 `prefers-reduced-motion` 合并生效。
- 默认宽度跟随容器，240–360px；高度232px。建议放在主题预览区域，保持自身完整边界，不覆盖旁边标题或替代Rin插画。

## 编排

1. 0–0.65s：10 枚围绕矩形样本台排列的双面材质瓣片依次沿真实铰链开合；每片相隔35ms，保留轴销、边缘厚度与背面蚀刻。
2. 0.65–1.5s：瓣片继续翻面至166°，中心5块不同尺寸的矩形/圆形样本沿交叉轨迹上升到不同高度，错峰旋转后交换位置。
3. 1.25–2.1s：横向穿梭梁越过样本阵列，再压回轨道；材质块回落到当前主题的组合位置。
4. 2.1–2.8s：外瓣依次封合，穿梭梁归位；约2.95s后完全静止，不循环晃动。

主题与强调色变化都会重新编排一次，全部颜色来自 props；没有独立于真实设置的伪状态。连续切换取消上一轮并组装最新配置。

## 交互与可访问性

- 进入视野时自然播放一次；主题和强调色变化时重新组合。
- 样本台使用固定观察角度，不提供拖动、键盘控制、重播或复位入口。
- 装饰性三维结构为 `aria-hidden`，材质名称与色值用于说明当前组合。
- 减少动态开启后直接显示最终组合，颜色与主题仍可即时更新。
- 动画中途开启减少动态时，所有运动分支 duration/delay 同时归零，立即收束；离屏或切换到后台也进入最终姿态，并记录该轮已完成，重新出现不会残留运动。
- 组件卸载和配色变化会清理上一轮结束计时器。
