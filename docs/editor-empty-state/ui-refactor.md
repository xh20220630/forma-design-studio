# 画布工作区重构

中央区域采用中性灰背板、固定在视口边缘的标尺、居中画板和底部悬浮工具栏。画板仍使用项目自身的宽高与背景色。新 Rin 插画作为画板的屏幕坐标覆盖层，保持清晰的固定字号；它不是项目图层，也不会进入设计导出。选择绘制工具或创建内容后收起空状态。

## 实现

- `useCanvasViewport` 统一管理适应页面、适应所选、缩放锚点和视口大小变化。保持原节点的页面坐标和滚动平移；画板周围各预留一屏空间。
- 默认以页面居中；百分比缩放保持可用视口中心，Ctrl / Command + 滚轮以鼠标所在点为锚。绘制过程中阻止滚轮缩放，避免改变拖动坐标基准。
- 标尺根据缩放选择 1 / 2 / 5 × 10ⁿ 的主刻度，刻度始终对应实际画板原点。
- 空态提供画框、文字工具入口和凛协作入口。高度不足 300 px 时收起协作链接，避免挤出画板；极小画板不显示覆盖层。
- 图层栏折叠只动画化宽度，清除原 min-width 对 44 px 收起状态的限制。

## 验证

- 独立内存测试页：1440 × 980 和 960 × 900，未写入实际项目数据。
- 画框拖绘、文字创建、撤销与空态恢复通过；29% 缩放下页面中心创建文字的坐标为 (720, 450)。
- 适应所选中心偏差不足 1 px；400% 缩小至 25% 后页面中心偏差为横向 0、纵向 0.5 px。
- 100 × 50 px 的手型拖动得到相同屏幕平移距离。
- 图层栏从 220 px 收至 44 px，中央区域由 480 px 增至 656 px，适应缩放从 29% 调整至 41%。
- 257.5 px 高画板内空态高 234.58 px，上下各留 11.46 px，工具栏完整且无横向溢出。
- 几何定向验证：9 组居中、36 组缩放锚点、9 组视口变化、3 组滚动限制边界通过。
- `npm run build` 通过（TypeScript 检查 + Vite 生产构建）；未运行 lint。临时测试页已删除，未使用 pnpm。
