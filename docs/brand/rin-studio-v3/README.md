# Forma · Rin Studio / 当前界面设计

本版根据“黑白高级感、彩色冷酷 Q 版少女、少量天蓝点缀”的反馈重新设计，替代 `rin-atelier` 目录中的早期界面方案。项目是最大的业务单元，页面、组件、设计变量和同步配置属于项目；工作空间负责项目集合、模板和模型配置。

## 完成的页面

- 项目首页：自然语言入口、项目筛选/搜索/排序、网格和列表、真实页面预览、模板入口。
- 项目概览：紧凑资源栏、大幅设计页面预览、设计系统、代码工作空间、项目上下文聊天入口。
- 画布：重排顶部和浮动工具栏、图层/资源入口、可折叠两侧面板、清晰属性分组。窄窗口打开聊天时优先保证设计区域宽度。
- 组件库：分类、搜索、紧凑目录、组件展示和操作弹层。
- Tokens：变量分组和实时主题预览；主题模式、字体、颜色与布局变量。
- 代码同步：绑定、检查、应用三个阶段；真实变更预览和结果状态。
- 模板、Agent 管理与设置：统一间距、导航、字段、状态和操作层级。
- Agent 聊天：工作空间/项目上下文、四个任务入口、历史会话、任务轨迹、设计图确认、固定输入区。

首页提交只将需求带到聊天草稿并聚焦，用户仍控制正式发送。真实模型请求、设计图确认、项目版本冲突和同步检查沿用业务接口。

## 动效

React Motion 用于路由进入、页签指示器、卡片布局变化、悬停/按压、画布面板、聊天与任务反馈。全局默认过渡 220ms；进入曲线为 `[0.16, 1, 0.3, 1]`。关键布局采用弹簧，系统“减少动态效果”偏好会减少或关闭相应动画。

[Blender 源文件与制作说明](../rin-motion/README.md) / [品牌组件演示](http://127.0.0.1:5173/docs/brand/rin-motion/preview.html)

工作室演示为真实 Blender 场景：彩色人物是 2.5D 肖像平面，周围 token、组件与画布为 3D 几何。视频为 720×480、25fps、5 秒、VP9、无音频，约 256 KiB。项目概览中默认静态，用户主动播放；任务中的动画由真实执行状态控制。视口外或页面后台暂停，减少动态效果时显示静帧。
