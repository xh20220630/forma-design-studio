# 画布能力与交付边界

Forma 采用 Figma 风格的工作台组织方式，并使用 shadcn/ui 基础控件。它是可编辑的本地设计系统，当前版本不能声称已经覆盖或超过 Figma 的全部能力。本表描述本仓库实际实现，方便逐项验收。

| 范围 | 当前实现 | 边界 |
| --- | --- | --- |
| 工作台 | 项目、模板、组件、变量、Agent、同步、设置；画布图层面板、设计/原型/开发属性面板 | 本地单用户工作空间 |
| 场景节点 | 页面、画框、分区、编组、矩形、椭圆、直线、多边形、星形、路径、文字、图片、按钮、组件实例 | 不读取 `.fig` 文件 |
| 编辑 | 多选、移动、缩放、旋转、翻转、对齐、分布、复制粘贴、排序、重命名、隐藏、锁定、撤销/重做 | 不提供完整的 Figma 矢量网络 |
| 视图 | 缩放、平移、适应画布、适应选区、标尺、网格/列布局网格、吸附提示 | 固定画布尺寸；无 GPU 大规模场景优化保证 |
| 视觉属性 | 纯色、双色线性/径向渐变、描边/虚线、圆角、单个阴影、图层模糊、透明度、六种混合模式 | 不支持多重填充/多重效果、任意蒙版、背景模糊、纹理填充 |
| 文字 | 字号、字重、斜体、行高、字距、水平/垂直对齐、下划线/删除线 | 不支持同一文本节点内的多种字体样式、变量字体轴、完整排版引擎 |
| 矢量 | 点路径编辑；SVG path 坐标指令渲染；基本图形；同父级矩形/椭圆/多边形/星形/闭合 M/L 路径的联合、减去、相交、排除 | 椭圆与圆角采用分段近似；结果为可再次运算的扁平路径，不能编辑布尔操作树；不支持贝塞尔手柄编辑；多边形/路径描边位置按中心渲染 |
| 自动布局 | 编辑时计算横向、纵向、换行、间距、内边距、对齐、适应内容、主轴剩余空间分配与交叉轴填充 | 写入固定坐标，导出后不会变成完整的响应式 CSS 布局求解器 |
| 约束 | 编辑时父容器调整触发左右/上下固定、居中、双侧拉伸、比例缩放 | 非通用约束求解；复杂嵌套布局仍需验证 |
| 组件 | 创建主组件、引用实例、修改主组件、变体分组和属性、交换/分离实例、重置覆盖 | 实例覆盖支持文本、颜色、可见性；无远程团队库发布协议 |
| 主题与变量 | 主题 token 绑定；项目主题模式；颜色/数值/字符串/布尔变量集合及模式；节点变量绑定 | 不支持变量别名链与任意表达式求值 |
| 原型 | 点击/悬停、页面跳转、浮层、返回、安全 HTTP(S) 链接；即时/淡入/滑动 | 不支持 Smart Animate、条件表达式、滚动交互、复杂手势与设备模拟 |
| 评论与版本 | 页面定位评论、解决状态、手动命名快照、恢复设计数据 | 本地持久化；无多人在线评论推送、CRDT、分支合并或审计系统 |
| 资源与交付 | 位图和安全 SVG 资源；JSON/SVG/PNG 导出入口；共享 React 渲染器；受保护的工作空间同步 | SVG 画布导出使用 foreignObject；部分第三方 SVG 消费软件可能不支持。远程图片可能受跨域限制影响 PNG 导出 |
| AI | 主题生成、图片生成、确认后还原可编辑节点、REST Agent 接口 | 需要兼容模型配置；不承诺截图像素级复刻与跨次生成完全一致 |

## 场景和导出的共同语义

`src/components/SceneRenderer.tsx` 是编辑器预览与导出 React 的共同渲染源。导出器直接嵌入这份源代码和类型，避免编辑器与消费应用分别维护两个不同的视觉实现。

- 节点数组顺序决定叠放，节点位置保存在所在页面或组件的绝对坐标系中。
- 父节点的隐藏、透明度、旋转、翻转会传播到后代。裁剪当前使用祖先的轴对齐矩形，旋转容器的精确裁剪未实现。
- 图片通过 `<img>` 渲染，文本始终使用 React 文本转义。路径只能是受限的 SVG `d` 坐标字符串，不执行 HTML 或 SVG 脚本。
- 组件实例通过 `componentId` 解析对应主组件，按实例尺寸缩放。实例覆盖在 token 与变量解析之后应用，因此明确覆盖不会被主题绑定悄悄替换。
- 主题模式决定使用的 token 值；变量模式决定绑定值。没有新增字段的旧项目继续使用原来的 `tokens` 和节点属性。
- 快照保存页面、组件、tokens，并可保存主题模式和变量集合。旧快照缺少这些可选字段时仍可读取。
- React 导出提供原型的基本页面切换与浮层交互，以及 `onAction(nodeId)` 接口。业务应用的数据、鉴权、路由集成和生产部署由消费项目负责。

## 后续实现所需的独立工程

要达到完整专业设计软件的覆盖度，仍需构建矢量网络与可编辑布尔操作树、完整蒙版与多重效果、高级文字系统、实时协同与权限、团队库与发布、完整响应式布局、复杂原型执行器、设计分支合并以及外部 Figma 文件/版本适配层。这些能力不应由外观相似或未实现的按钮代替。
