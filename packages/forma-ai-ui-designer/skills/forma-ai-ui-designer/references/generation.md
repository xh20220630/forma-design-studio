# 图片生成与验收

使用当前可用的真实生图工具，优先内置 imagegen。不得用 HTML/CSS 截图、SVG 或文字拼图冒充生成的产品 UI 图片。

桌面默认目标 1920×1080。移动端先确定逻辑视口和倍率。工具不支持目标尺寸时记录真实像素与偏差；只有用户明确接受后才能交付偏差尺寸。

每页 Prompt 固定包含主题版本、具体 Tokens、框架、字阶、密度、控件语言、基准参考图和画布尺寸，并补充页面目标、信息层级、真实数据、动作、状态和组件适配。图片内不包含业务标注箭头。

逐图打开检查：

1. 页面、弹层、状态、核心动作和业务字段完整；
2. 导航、栅格、颜色语义、字阶、间距和控件语言一致；
3. 中文、数字、表格与错误提示可读；
4. 加载、空、错误、权限、确认和撤销有解释；
5. 文件、实测尺寸、主题/组件版本、Prompt 和参考图可追溯。

问题图片创建新版本并保留历史文件。未解决问题在交付说明中写明，不写入评审状态。
